# Dataset procesado y normalizado

Esta carpeta contiene el dataset normalizado utilizado en el proyecto final de Data Analytics de Coderhouse.

El archivo incluye las tablas de goles, partidos, competiciones, clubes, posiciones y jugador.

Los datos fueron preparados para construir el modelo relacional y desarrollar las visualizaciones e indicadores en Power BI.

El dataset original se encuentra en la carpeta data/raw/.
