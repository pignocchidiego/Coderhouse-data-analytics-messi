# Dashboard de Power BI

Esta carpeta contiene el dashboard interactivo desarrollado como proyecto final del curso Data Analytics de Coderhouse.

El archivo Power BI (.pbix) permite explorar el rendimiento goleador de Lionel Messi mediante indicadores DAX, filtros y visualizaciones interactivas.

También se incorporarán capturas de las distintas páginas del dashboard para visualizar los resultados sin necesidad de descargar Power BI Desktop.
